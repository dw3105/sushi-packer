---------------------------------------------------------------------------------------------------
Version: 0.2.8
Date: 2026-09-28
  Changes:
    - Each lane owns 24 of the 48 slots: a blocked output lane no longer stops the other lane.
    - Each lane holds at most one full item stack of each item and quality (modded stack sizes included); more waits on the belt.
    - Status light turns red when one lane is full.

---------------------------------------------------------------------------------------------------
Version: 0.2.7
Date: 2026-09-27
  Bugfixes:
    - Box now takes items from a splitter, loader or linked belt right behind it and sends stacks into a splitter, loader or linked belt right in front of it (lane kept).

---------------------------------------------------------------------------------------------------
Version: 0.2.6
Date: 2026-09-27
  Bugfixes:
    - Fixed one output lane stopping for good when an overloaded belt brings stacked items: a full box now hands freed slots to both lanes in turn.
    - Belt stack size now follows belt stacking research exactly, including mods that raise it above 4.
  Changes:
    - Tooltips and tips describe stack size as set by research.

---------------------------------------------------------------------------------------------------
Version: 0.2.5
Date: 2026-09-27
  Bugfixes:
    - Fixed crash when a blueprint (or any item window) is open: "LuaItemStack doesn't contain key unit_number".
  Changes:
    - New mod thumbnail.

---------------------------------------------------------------------------------------------------
Version: 0.2.4
Date: 2026-09-27
  Bugfixes:
    - Box no longer makes items stop at belt end: it wakes exactly when next item arrives (no stutter).
  Changes:
    - Factoriopedia and tip scene show only belt, box, belt; box centered, feeding machinery off screen.

---------------------------------------------------------------------------------------------------
Version: 0.2.3
Date: 2026-09-27
  Changes:
    - Factoriopedia and tip scene rebuilt: four chests, yellow inserters feed both belt lanes, box packs 4-stacks.

---------------------------------------------------------------------------------------------------
Version: 0.2.2
Date: 2026-09-26
  Changes:
    - Box releases as soon as one item kind fills a belt stack (1 to 4 with research), not a full item stack.
    - Renamed to vanilla belt series: Sushi packer, Fast, Express, Turbo sushi packer (old saves migrated).
    - Own crafting menu row after belts, sorted by tier.
    - Settings window: aligned sections, 10-slot skip filter with splitter-style quality rule, circuit network section.
  Features:
    - Live Factoriopedia and tip scene.
    - Box marked for deconstruction stops and turns its LED off.
    - Box can be placed straight over a belt (belt cannot replace a box).
