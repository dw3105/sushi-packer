## Explain very simply

Front belt jams. Today packer keeps taking iron until whole lane store (24 slots) is iron. Author wants: one kind holds at most one item stack per lane (e.g. 50 ore, 100 plates); when store drops to half a stack, kind is taken again. Rule and its code exist (script way since v1.15). We switch it on for engine way: one call at each look, and mop arms obey it too. Free belt: no kind ever reaches a stack, so no filter is ever written (costs nothing).
