## Explain very simply

Packer window lists what each lane holds. Same item in two qualities shows as two slots that look the same. Each slot must show its quality, like game inventories do.

## What to build

### Facts about current `scripts/gui.lua`

- `build_lanes(frame, unit, rec)` makes per lane 12 `sprite-button`s named `lane_slot_<n>` (style `slot_button`); `refresh_lane_buttons(frame, rec)` fills them from `lane_stack(rec.invs[lane], slot)` (a `LuaItemStack` or nil): sprite `item/<name>`, number = count; empty slot: sprite nil, number nil. `M._refresh(player, rec)` and `M._refresh_open(player)` call it every 30 ticks.
- `quality_items()` already lists non-hidden qualities sorted by level (used by filter editor).
- Game API (2.0 and 2.1): `LuaGuiElement` of type `sprite-button` has writable `quality` (QualityID or nil): game draws the quality mark on the button. `LuaItemStack.quality` is a `LuaQualityPrototype` (`.name`). Tooltip: `elem_tooltip = { type = "item-with-quality", name = <item>, quality = <quality name> }`.

### Tests first — in `tests/offline/test_gui.lua` (describe `gui v20`); each seen RED before code. Fake buttons are plain tables: assert the fields written.

- `gui v20 > lane slot shows quality of its stack` — store slot holds `{ name = "copper-cable", count = 114, quality = { name = "rare" } }`: button `sprite == "item/copper-cable"`, `number == 114`, `quality == "rare"`, `elem_tooltip` = `{ type = "item-with-quality", name = "copper-cable", quality = "rare" }`.
- `gui v20 > normal quality is written too` — quality `normal`: `quality == "normal"` (game shows no mark for lowest quality by itself).
- `gui v20 > empty slot clears quality and tooltip` — slot that held rare cable, now empty: `sprite == nil`, `number == nil`, `quality == nil`, `elem_tooltip == nil`.
- `gui v20 > refresh updates quality in place` — same button object, stack changes from rare to epic: `quality == "epic"`; no button destroyed or added.
- `gui v20 > stack without quality field` — fake stack with `quality == nil` (old fakes): no error, `quality == nil`.
